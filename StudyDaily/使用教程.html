StudyDaily 从零到用

幼小衔接课件自动排课 · 具体操作教程　|　全程约 10 分钟操作 + 一次后台转码

一、到底自动还是手动？

结论：全自动，不用写课表，也不用编辑任何 JSON 文件。你只需要把原始课件按单元放进文件夹、用文件名前缀排好顺序；剩下的全部由程序完成。

环节谁做说明
把课件分单元、按顺序命名你手动唯一需要动手的「规划」，本质只是整理文件夹
转码、生成 courses.json 课程清单自动跑一条命令，几百个文件一次处理完
决定今天学哪几节自动每天首次打开时按当前进度实时计算，不是提前排好一整年的课表
没学完顺延、到期复习自动昨日未完成原序置顶，学完进入 1/3/7/15 天复习
播放进度、完成记录、热力图自动自动写入，不用打卡登记
改每日时长 / 跳课 / 临时加一节家长可选微调在家长端点几下即可，不影响整体自动规划
两层的区别很重要：courses.json 是「有哪些课、按什么顺序」的静态清单，导入一次就固定；「今天学哪几节」是每天打开时根据完成了多少、欠了多少、哪些该复习临时算出来的。所以孩子落下一天，第二天会自动顺延，不需要你重新排课表。
六步速查（照着做即可）：
  1. 课件按 01 拼音 / 02 识字 / … 分文件夹，文件名加数字前缀
  2. python tools/prepare_courses.py --src "D:/幼小衔接课程" --dry-run 先看报告
  3. 去掉 --dry-run 正式导入，自动生成 courses.json
  4. 把整个 StudyDaily 文件夹拷进平板
  5. 平板装本地 HTTP 服务器 App 指向该文件夹 → Chrome 打开 → 添加到主屏幕
  6. 孩子每天点桌面图标，今天学什么由系统自动算好

二、电脑上的准备（只做一次）

本项目文件夹里已经带有全部脚本，只要电脑上有 Python 3.9+ 和 FFmpeg。有 PDF 课件时再装一个渲染库：

python --version
ffmpeg -version
pip install pypdfium2        # 只有用到 PDF 时才需要

缺 FFmpeg：Windows 到 gyan.dev/ffmpeg/builds 下载 essentials 版，解压后把 bin 目录加入系统 PATH，重开终端。

1

整理原始课件（唯一需要你动手的「规划」）

把课件按单元放进子文件夹，文件名前面加序号。视频和 PDF 可以混在一起，按文件名自然排序：

D:/幼小衔接课程/ ├── 01 拼音/ │ ├── 01 a o e.mp4 │ ├── 02 拼音描红练习.pdf │ ├── 03 i u ü.ts │ └── 04 b p m f.mkv ├── 02 识字/ │ ├── 01 一二三.mp4 │ ├── 02 田字格练习.pdf │ └── 03 人口手.mp4 └── 03 数学思维/ ├── 01 10 以内数数.mp4 （H.265 也可以，会自动转） └── 02 比多少.mp4

命名规则（决定学习顺序）：

  • 文件夹名前缀数字 = 单元顺序，01 拼音 排在 02 识字 前面
  • 文件名前缀数字 = 课顺序，用自然排序：1、2、3 … 10，不会排成 1、10、2
  • PDF 和视频一视同仁，例如 02 拼音描红练习.pdf 就是第 2 节
  • 文件名可以带中文和空格，脚本会自动输出成纯英文路径，不用改名字
  • 单元名带上科目关键词（如 01 拼音、02 识字、03 数学、04 英语），系统会据此识别科目并按星期排课；不用写「第几天学什么」的课表
2

先跑一次预演（不写任何文件）

cd StudyDaily
python tools/prepare_courses.py --src "D:/幼小衔接课程" --dry-run

会看到类似输出：

扫描完成：286 个视频 + 18 个 PDF，3 个单元
[1/304] OK  copy     01 a o e
[2/304] OK  pdf      02 拼音描红练习
[3/304] OK  remux    03 i u ü
[4/304] OK  full     01 10 以内数数
分类统计：copy=180，remux=42，audio=6，full=58，pdf=18

这一步只出报告，不写文件。报告在 transcode-report.json，可以核对数量、分类和有没有失败项。

常用可选参数：

参数作用
--scale 0完全保留原始分辨率（默认上限 720p，480p/540p 本来就不会被放大）
--scale 1080允许到 1080p
--pdf-minutes 5PDF 课默认时长（分钟），页数多时按每页 1 分钟自动上调
--jobs 4并发数，电脑性能好可以调大
--force改动过原始文件后强制重新处理
3

正式导入

python tools/prepare_courses.py --src "D:/幼小衔接课程"

几百个文件通常几十分钟到几小时，放着跑就行。中途可以关掉，重跑会自动跳过已完成的。完成后项目目录变成：

StudyDaily/ ├── index.html 应用本体 ├── courses.json ← 自动生成的课程清单 ├── videos/u01/001.mp4 ← 统一 H.264+AAC MP4 ├── files/u01/002.pdf ← 保留的 PDF 原件 ├── pages/u01/002/p001.jpg ← PDF 每页转出的图片 ├── transcode-report.json 处理报告 └── tools/ 脚本，平板用不到但可一起拷

courses.json 里每一节大致长这样，不需要你手写或修改：

{
  "id": "u01-002",
  "title": "拼音描红练习",
  "type": "pdf",
  "file": "files/u01/002.pdf",
  "pages": ["pages/u01/002/p001.jpg", "pages/u01/002/p002.jpg"],
  "pageCount": 2,
  "durationSec": 300,
  "order": 2
}
想调整顺序怎么办？回去改原始文件名前缀（例如把 05 改成 02），删掉旧的 courses.json 再跑一次脚本（或加 --force）。应用检测到清单变化后，当天就会自动重排今天的任务，不用等到明天。

三、上平板（只做一次）

4

安装 App（StudyDaily.apk）

把 StudyDaily.apk（约 14 MB）发到平板，点一下安装。系统可能提示「未知来源应用」，允许一次即可。装好后桌面出现 「每日学习」 图标——点开就是全屏儿童界面，不用开浏览器、不用装服务器 App、不用拷任何文件夹、也不用给存储权限。

5

打开就能学（视频云端点播）

课程视频不占安装包：第一次点某节课时，App 会自动从云端边下边播（720p 只需约 100 KB/s，普通 WiFi 足够），同时把这集悄悄存到本机。之后这集就变成离线可用，没网也能看。

所以第一次看新的一集需要联网，看过的课不需要。家长端「设置 → 课程缓存」能看到已缓存多少集、占用多少空间，也可以一键清空；占用超过 2 GB 时自动删掉最久没看的。

如果提示「这一集还没存到本机」，说明当前没联网或网络被限制。连上 WiFi 后点「重试」即可，学习进度不受影响。

可选：整包拷进平板（完全离线）

要出门、担心网络不好，可以按老办法把整个 StudyDaily 文件夹拷到平板内部存储（路径 /内部存储/StudyDaily）。App 优先读本地文件，本地有就完全不联网；没有的再从云端补。两种方式可以混用。

备选：不装 App，用浏览器

如果平板装不了 APK，也可以：装 Simple HTTP Server 之类 App，共享目录指向 StudyDaily 文件夹并开启「开机自启」；Chrome 打开它显示的地址（通常 http://127.0.0.1:8080/）→ 菜单「添加到主屏幕」。

视频必须走 HTTP 才能播放，直接双击 index.html 会黑屏（file:// 被 Chrome 禁止加载本地视频）。这条路线每次要先启动服务器 App，而且进度存在浏览器里，记得定期「导出进度备份」。

四、每天怎么用

7

孩子端：点图标就用

  • 首页只有「今天这几节」大按钮，看不到后面的课程，不会乱点
  • 点一节 → 播放（或 PDF 翻页）→ 看到 90% 自动进入「闯关小游戏」→ 做完 3 道小题才记完成 → 自动进入下一节
  • 全部完成显示「今天的任务完成啦」并锁住
  • 连续学 2 节后会提示起来动一动、看看远处
为不识字的孩子做的设计：界面不用读字——小熊形象引导、每节课一张「缩略图 + 大序号 + 学科图标」的卡片、一排小星星表示今天进度。语音引导已内置在应用里（温柔女声、语速放慢，共 403 句、约 9.6 MB，完全离线）：打开会说「今天有 N 节课」，点进一节会念出「这一节是拼音，第 1 集」，学完表扬「太棒了」。不需要平板装任何语音引擎。在公共场合可在家长端 → 设置里单独关语音、只留音效；图标插画来自微软开源 Fluent Emoji（MIT 许可），随应用打包，也不联网。

顺延示例：今天排了 4 节共 30 分钟，孩子只学完 2 节。明天打开时，剩下 2 节会原顺序置顶，再加当天该复习的课，然后再补新课，总时长仍然是 30 分钟，不会因为欠账而加量。周末额度自动变成 15 分钟。

每周课程安排（自动按星期排课）：不再是「一门一门从头学到尾」，而是识字每天都学，第二科按星期搭配——
星期搭配说明
周一 / 周三识字阅读 ＋ 数学语文指读搭配数感游戏
周二识字阅读 ＋ 拼音拼音以听音、认形为主
周四识字阅读 ＋ 英语英语避开拼音日，防止发音混淆
周五识字阅读 ＋ 数学 / 拼音默认隔周自动轮换；家长端「设置」可固定为数学或拼音
周六自由拓展各科都可排，按课程自然顺序出
周日休息 / 复盘不排新课，只出到期复习；没学完的顺延到周一
每个科目内部仍然严格按集数顺序学，绝不跳课；系统保证当天搭配的两个科目都会出现（第二科单节较长时，允许比预算多出 10 分钟以内，例如识字 13 分钟＋数学 23 分钟＝36 分钟）。没学完的复习不会一天天顺延堆积，每天最多补 2 节，其余顺延到后面几天。首页日期旁会显示「今天学：识字阅读 ＋ 数学」这样的当日主题。

四点五、学完后的「闯关小游戏」

看完一节课，不再直接跳下一节，而是先进入一个 1 分钟左右的小游戏：小熊带着孩子走三级台阶，每答对一题升一级，走完三级拿到奖杯才能算「学完」。目的是把刚看的内容马上用一遍，加深记忆。

科目出的题（每节 3 题，自动按本节内容生成）
拼音找出一样的字母（b 和 d 这类形近字母专门练）、听「呼读音」选声母、形近字母找不同
识字听读音选汉字、看图选字（图是真实插画，不是抽象符号）、字形匹配
数学数一数、加减法、比较大小多少、认钟表（整点/半点）、认图形、找规律
英语听英文童声「Find big B / Find small b」找字母、形近字母辨析
  • 每道题都有语音，孩子不需要识字也能做题；英语题用英文童声朗读，中文题用和小熊一样的女声
  • 答错不打叉、不扣分：那张卡片只是变暗，语音说「再试一次，仔细听」并重播题干；同一题错两次，正确答案会轻轻发亮，保证孩子最后一定能过关
  • 答对有星星爆炸、连对显示「连对 2 题！」，全对有奖杯和撒花
  • 右上角 ✕ 可以先不做题（比如孩子在公共场合不方便出声），不影响正常排课
  • 家长端「课程」里每节课有「看题目」按钮，可以先替孩子试玩一遍；「统计」里新增了做题数、答对率和「这几节可以再看一遍」
  • 不想要可以在家长端 → 设置里关掉「学完出三道小题」，恢复原来的直接进入下一节
题目从哪来？全部按每一节课的实际内容自动生成（拼音课出这节课的字母、识字课出这节课的字、数学课按课题出数数或加减），共 372 题、约 211 句语音，已离线打包，不联网、不含广告。想改题就在电脑上编辑 tools/build_quiz.py 后重跑 python tools/build_quiz.py，再执行 python tools/make_voice.py 补语音。

四点六、练习册书架（纸质练习册的电子版）

导入的《春雨幼教·幼小衔接整合教材》12 本（拼音/识字/数学/英语，教材上下册 + 每日一练，共 619 页）已经放进应用。孩子首页有一个黄色「练习册」大按钮，点开是书架：每本书显示真实封面，点开像翻纸质练习册一样一页一页看，照着屏幕上的题在纸上做。

  • 每本书都会记住看到第几页，下次翻开接着做；书架封面下方会显示「看到第 X 页」
  • 翻开时小熊会念书名并提示「点下面的箭头翻页」，孩子不识字也能自己操作
  • 练习册不占用每天的 30 分钟，也不影响排课，随时想看就看；翻到最后一页会提示「这是最后一页啦」
  • 这些扫描页占用约 59 MB，放在平板 /内部存储/StudyDaily/workbooks/ 文件夹里，不占 APK 空间。把整个 StudyDaily 文件夹拷到平板时练习册就一起带过去了
  • 想加新书：把 PDF 放进一个文件夹，在电脑上运行 python tools/build_workbooks.py --src "PDF所在文件夹"，再运行 python tools/make_voice.py 补语音，最后重新打包安装
8

家长端：连点右上角齿轮 5 次（或长按）

输入 PIN（默认 1234，可在设置里改）进入，这里是唯一可以「手动干预」的地方：

标签页能做什么
今日上移/下移只改今天的顺序、跳过某节、手动标完成、标「没学会」（次日重看）
课程看全部课程状态、把某节临时加到今天、恢复已跳过的课、点「看题目」预览这节课的小题
统计总进度、连续天数、最近 12 周热力图、累计学习时长、做题数与答对率
设置改平时/周末分钟数、复习开关、完成判定比例、PIN，导出/导入进度备份
帮助本教程的精简版，随时在平板上查
关于备份：用平板现成 HTTP 服务器 App 时，进度存在浏览器里，建议每周在「设置 → 导出进度备份」下载一个 JSON 存到网盘。清理浏览器数据后用「导入备份」即可恢复。如果改用自己的 tools/serve.py，进度会自动写进 progress.json，不用手动导。

五、出了问题查这里

现象处理
视频黑屏 / 播不动编码不是 H.264+AAC，重跑脚本并加 --force
能播但不能拖进度条换支持 Range / 断点续传的 HTTP 服务器 App
课程顺序不对检查原始文件名前缀数字，改完重跑脚本
换了课件但首页没变确认 courses.json 已替换后刷新；应用会自动重排今天
PDF 显示「用系统阅读器打开」电脑执行 pip install pypdfium2 后加 --force 重跑
平板打不开页面确认两台在同一 WiFi、服务器 App 正在运行、电池优化已关闭、端口和 App 显示一致
